# Legacy Brain

Внутренняя операционная система Legacy Imperial Concerts. Репозиторий содержит два интерфейса над одной базой данных:

- `https://daria-bing.vercel.app/` — полный Legacy Brain для концертов, продаж, расходов, каналов, документов, задач, регламента и отчётов;
- `https://daria-bing.vercel.app/ops/` — «Всё под рукой», компактный Telegram-пульт для ежедневной работы и проверок запуска.

Оба интерфейса читают и меняют общие записи Supabase. Отдельных копий концертов, задач и документов для Telegram-пульта нет.

## Границы системы

- Источник операционной правды — подтверждённые записи и прикреплённые документы, а не показатели рекламной площадки сами по себе.
- Система не принимает финансовых решений и не запускает рекламу. Она показывает расчёты, пробелы и сигналы для решения команды.
- Продажи, деньги на счетах и рекламные показатели хранятся раздельно.
- Автоматические интеграции с рекламными кабинетами и билетными операторами пока не реализуются. Данные вносятся формами, документами и проверяемым импортом.

## Карта исходного кода

- `index.html`, `styles.css`, `app.js` — полный интерфейс Legacy Brain.
- `ops/` — Telegram-пульт «Всё под рукой».
- `api/` — серверные методы и проверка доступа Telegram.
- `shared/regulation.js` — общие 12 шагов регламента запуска.
- `supabase/migrations/` — последовательные дополнения структуры базы данных. Старые миграции не переписываются.
- `tests/` — проверки архитектурных границ, форм, расчётов и обоих интерфейсов.
- `docs/ПОЛНОЕ_РУКОВОДСТВО_LEGACY_BRAIN_2026-10-07.md` — актуальный текст полной инструкции, обновлённый 13.10.2026.
- `scripts/render_full_manual.py` — сборка PDF-инструкции на рабочий стол.

## Проверка перед отправкой изменений

1. Запустить `npm test` и убедиться, что все проверки прошли.
2. Проверить `git diff --check`, чтобы не отправить повреждённые строки или лишние пробелы.
3. Отправить изменения в ветку `main` репозитория `dmytroo-gmx/daria_bing`.
4. Дождаться сборки Vercel и сравнить живые файлы с текущим коммитом.
5. Проверить `https://daria-bing.vercel.app/api/ops-health`: состояние базы и запросов пульта должно быть `ready`.
6. Изменения форм и прав доступа дополнительно проверить после входа разрешённой ролью. Автоматические тесты не заменяют эту проверку.

## База данных

Миграции применяются по порядку от `0001` до последней. На 13.10.2026 последняя миграция — `0023_new_era_regulation.sql`. Перед добавлением следующей миграции нужно проверить, что она только дополняет текущую структуру и не перезаписывает существующие данные.

## Инструкция для команды

PDF создаётся командой `python scripts/render_full_manual.py`. Текущий файл сохраняется на рабочем столе как `Legacy_Brain_Полная_инструкция_2026-10-07.pdf`. Название файла оставлено прежним, чтобы не ломать уже переданные ссылки; дата актуальности указана внутри документа.
